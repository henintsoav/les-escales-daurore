# Les Escales d'Aurore

> Voyager · Découvrir · S'émerveiller

Blog voyage construit avec **React + Vite**, déployé sur GitHub Pages.

## Stack

- React 18 + React Router v6
- Vite
- CSS Modules
- GitHub Actions (CI/CD → GitHub Pages)

## Lancer en local

```bash
npm install
npm run dev
```

## Déploiement

Le déploiement est automatique sur `main` via GitHub Actions → GitHub Pages.
